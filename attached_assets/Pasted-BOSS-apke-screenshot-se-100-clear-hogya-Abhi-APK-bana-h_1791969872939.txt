### 🔥 MANUAL FIX - 2 File Banao - 100% Kaam Karega

*STEP 1: Code tab > `android-apk.yml` ko sahi karo*

Us file ko kholo > Pencil ✏️ > Saara delete karke YE FINAL CODE paste karo:
name: Build Chouhan SUPER APP APK
on:
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Install Buildozer Deps
        run: |
          sudo apt update
          sudo apt install -y openjdk-17-jdk zip unzip libffi-dev libssl-dev libtool autoconf cmake
          pip install buildozer kivy cython==0.29.36 groq requests
      - name: Build APK
        run: |
          rm -f buildozer.spec
          buildozer init
          sed -i 's/title = My Application/title = Chouhan SUPER APP/' buildozer.spec
          sed -i 's/package.name = myapp/package.name = chouhansuperapp/' buildozer.spec
          sed -i 's/package.domain = org.test/package.domain = com.chouhan.superapp/' buildozer.spec
          sed -i 's/#android.permissions =/android.permissions = INTERNET,RECORD_AUDIO,WRITE_EXTERNAL_STORAGE/' buildozer.spec
          sed -i 's/requirements = python3,kivy/requirements = python3,kivy,groq,requests/' buildozer.spec
          buildozer -v android debug
      - name: Upload APK
        uses: actions/upload-artifact@v4
        with:
          name: Chouhan-SUPER-APP-APK
          path: bin/*.apk
